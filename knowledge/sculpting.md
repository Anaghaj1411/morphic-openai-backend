# MORPHIC — Sculpting

MORPHIC is an interactive 3D digital sculpting project.

The player modifies virtual clay through interaction with the application.

The sculpting system can include deformation, transformation, and surface-editing operations.

The exact sculpting tools, gesture mappings, sculpture assets, and gameplay behavior are defined by the current Unity project and may change during development.

For AI feedback, relevant information should come from the current Unity state, such as the action being performed, recent results, progress, or a player question.

The AI provides suggestions, explanations, and creative feedback based on the current context.

The AI should not directly execute arbitrary Unity code or uncontrolled commands.
